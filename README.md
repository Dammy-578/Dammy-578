## 👋 Hey there, I'm Dammy

I build, break, and rebuild IT infrastructure, then write up what I learned. Mostly cloud/DevOps and cybersecurity, with a lot of Linux underneath.

**What I've been working on:**
- SIEM detections in ELK with Sigma rules mapped to MITRE ATT&CK, plus an end-to-end SSH intrusion investigation
- Containerized apps on Azure Kubernetes Service with autoscaling
- DNS and email servers, and scripting SDN controllers
- Testing and hardening a local LLM

Currently preparing for the **Microsoft Azure Administrator (AZ-104)** certification. Looking for a Winter 2027 co-op.

**Fun fact:** I am really, really good at playing chess ♟️
